### 一键更新

- 网页只从 `youboRepo/LostArkHelper` 的最新正式 Release 检查更新，不直接执行 Git 分支中的未发布代码。
- 安装前再次下载指定版本附件，核对发布页 SHA256 清单和压缩包内逐文件 SHA256，拒绝旧版、路径越界及损坏文件。
- 存在待核对的游戏操作时不会更新。下载期间持有游戏操作锁，停止调度后等待旧服务退出，再替换程序并启动新版。
- 原程序目录保留为同级的 `.previous` 目录。账号凭据、定时设置和历史在独立用户数据目录中，升级不会替换它们。
- 更新后本会话失效，Windows 再双击一次启动器打开工作台；Linux 执行 `./open-workbench.sh` 获取新链接。Linux 的 systemd 服务路径不变，不需重新安装自启。
- v0.2.0 没有此功能，需手动升级到 v0.3.0 一次；之后可在网页上更新。网页更新仅支持打包版，源码运行继续用 Git 或手动下载。

### 验证与边界

新增发行包内容校验、版本比较和更新 API 鉴权测试。Windows 与 Ubuntu 原生构建会检查真实冻结程序的内置版本、GitHub 更新检查和模拟发行包的替换/自动重启，全程不访问游戏接口。

此功能信任项目 GitHub Release 及其校验清单；SHA256 用于确认下载完整性，不等同于商业代码签名。首次使用仍可能显示 Windows 未知发布者提示。任务 6–11 的领取参数仍为推断，未逐项真实领奖验证；iPhone 真机全流程也需单独验收。
