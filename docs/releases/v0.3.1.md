修复服务器版静态资源权限，解决使用 systemd `DynamicUser` 部署时左上角 LOGO 返回 HTTP 500 的问题。

### 原因与修复

- 服务器 LOGO 曾被 macOS 源文件保留为 `0600`，打包后又保留了该权限。
- 服务以 systemd `DynamicUser` 运行，无法读取该文件，因此 `/assets/ark-helper-wordmark.png` 返回 500。
- 发布工具现在会把服务器包内目录统一写成 `0755`、普通文件统一写成 `0644`，发布校验会拒绝不可读取的服务器归档成员。
- 手工复制服务器文件时，部署说明也会要求执行相同的权限修正。

### 更新说明

- 已部署的服务器版可直接修正 `/opt/lostark-dashboard/dist` 为目录 `0755`、文件 `0644`，或替换为 v0.3.1 服务器包。
- Windows/Linux 用户可从 v0.3.0 起在网页“定时设置 → 版本更新”更新到 v0.3.1。
- v0.2.0 仍需要先手动升级到带网页更新入口的版本。
- iPhone 快捷指令功能没有变化；已导入 v0.3.0 的用户无需仅为本修复重新导入。

本次仅修复服务器静态资源发布权限并统一版本号，没有改变签到、领奖接口、白名单或账号数据结构。
