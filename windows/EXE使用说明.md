# 命运方舟助手 Windows 免 Python 版

适用 Windows 10/11 x64。程序已包含 Python 及网页资源，不用安装 Python、Node.js 或其他开发工具。

1. 将 LostArkHelper.exe 放到固定的本地目录，然后双击。
2. 程序后台运行，自动打开默认浏览器工作台。首次在账号管理粘贴官方活动链接，先查询核对。
3. 关闭浏览器不会退出服务。再次双击 exe 会打开已有服务的工作台。
4. 停止：定时设置 → 启动设置 → 停止本地服务。
5. 开机自启：在同一页面开启“登录 Windows 后自动启动”；旧源码版的启动记录请先关闭，再用 exe 版开启。

从源码版升级：先按 Ctrl+C 或在旧网页停止服务，再运行 exe。数据位置相同；同一 Windows 用户下可继续使用已有配置和记录，不要同时运行两版。

单文件启动时会先把运行库释放到临时目录，首次可能等待数秒。不要删除运行中的临时文件，不需要把 exe 放在 Python 目录。移动 exe 后应重新设置自启路径。

数据和日志：%LOCALAPPDATA%\LostArkHelper。游戏凭据由当前 Windows 用户 DPAPI 加密保存。换用户或重装系统可能需要重新导入。

本程序尚无商业代码签名，Windows 或安全软件可能提示未知发布者。请核对下载来源和 SHA256；不需要关闭防护软件。遇到启动失败请保留 service.log 供脱敏排查。

定时计划按北京时间执行，登录 Windows 且服务运行时才有效，电脑关机/休眠期间不能执行。避免与服务器同时调度同一账号。
