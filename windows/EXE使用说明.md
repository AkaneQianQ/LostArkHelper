# 命运方舟助手 Windows 免 Python 版 · 0.2.0

适用 Windows 10/11 x64。GitHub Release 提供 ZIP 压缩包，内含 Python 运行时和网页资源，无需安装 Python、Node.js 或其他开发工具。

1. **完整解压 ZIP** 到固定本地目录，保留所有文件及 `_internal` 等子目录，然后双击 `LostArkHelper.exe`。
2. 程序后台运行，自动打开浏览器工作台，无需保持终端打开。首次在账号管理粘贴官方 App 的完整活动链接，先查询核对。
3. 关闭浏览器不会退出服务。再次双击 exe 会打开已有服务的工作台。
4. 停止：定时设置 → 启动设置 → 停止本地服务；等待已经开始的操作完成后退出。
5. 开机自启：在同一页面开启“登录 Windows 后自动启动”。旧源码版或程序移动过位置时，请先关闭，再用新版开启以更新路径。

从旧版升级：先在旧网页安全停止服务，再替换程序文件。同一 Windows 用户的数据目录不变，不要同时运行两版。目录构建不能只拷贝 exe；单文件构建首次运行可能等待数秒释放资源到临时目录。

活动 2611，支持任务 ID 1–13。**ID 6–11 的领取参数由已有接口推断，尚无真实成功抓包验证**；仅在官方返回 status=1 时尝试，提交后查询确认，结果不确定时立即停止并保留待确认记录。程序不能自动完成副本、累计签到等任务条件，首次查看规则也需要官方先认定完成。

数据和日志：`%LOCALAPPDATA%\LostArkHelper`。游戏凭据使用当前 Windows 用户 DPAPI 加密；换用户或重装系统可能需要重新导入。不要分享数据目录和带 key 的启动链接。

程序尚无商业代码签名，Windows 或安全软件可能显示未知发布者。请核对下载来源和 SHA256。遇到启动失败，可保留脱敏 `service.log` 排查。

计划按北京时间执行，登录 Windows 且服务运行时才有效，电脑关机/休眠期间不能执行。避免与服务器同时调度同一账号。详细任务范围、升级说明和构建方式见 `README.md`。
